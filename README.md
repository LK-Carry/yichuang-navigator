医创导航（Yichuang Navigator）
项目简介
医创导航是一款面向大学生的科研竞赛智能备赛平台，旨在帮助学生更高效地理解赛事规则、规划备赛任务、管理参赛材料并跟踪项目进度。

解决的问题:
赛事通知分散，报名条件和提交要求不容易快速梳理。
备赛任务缺乏清晰的时间安排与完成标准。
参赛材料和开发记录容易遗漏。
学生难以持续跟踪项目进展。

核心功能规划:
1.赛事信息录入与管理。
2.赛事规则提取与原文核对。
3.个性化备赛任务生成与管理。
4.项目进度跟踪和材料清单检查。
5.AI 辅助开发过程与迭代记录管理。

开发原则:
优先实现真实、可验证的核心功能。
优先采用免费工具和公开数据。
对 AI 提取的信息保留原文依据，避免将未经核实的内容当作官方规则。
保留真实、连续的 Git 提交历史和 AI 协同开发记录。

当前状态:
项目处于早期规划阶段，核心功能尚待开发和测试。

技术路线:
首版计划采用适合初学者的 Web 技术方案，具体技术栈将在开发验证后确定。

免责声明:
本项目提供赛事信息整理与备赛辅助，不代替赛事组委会发布的正式通知。报名资格、截止日期和提交要求应以官方信息为准。
